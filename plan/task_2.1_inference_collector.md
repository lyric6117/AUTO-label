# 任务 2.1：推理采集模块开发 - 执行计划

## 任务目标

实现 YOLO 模型推理和结果采集，输出标准化的检测结果 JSON 格式。

## 执行内容

### 1. 实现 agent/inference.py

#### 功能需求
- 加载 YOLO 模型
- 单张图片推理接口
- 批量推理接口
- 输出标准化的检测结果 JSON 格式

#### 输出格式
```json
{
  "image": "xxx.jpg",
  "detections": [
    {
      "cls": "fault_A",
      "conf": 0.91,
      "bbox": [x, y, w, h]
    }
  ]
}
```

#### 关键要求
- 保留原始置信度（关键）
- bbox 格式：[x, y, w, h]（中心点坐标 + 宽高）
- 类别名称使用配置文件中定义的名称

### 2. 实现推理结果验证
- 检查输出格式
- 验证 bbox 坐标有效性
- 验证置信度范围 [0, 1]

## 执行步骤

1. 实现 InferenceCollector 类
   - __init__: 加载模型和配置
   - predict_single: 单张图片推理
   - predict_batch: 批量推理
   - _format_result: 格式化输出结果

2. 实现结果验证函数
   - _validate_bbox: 验证 bbox 坐标
   - _validate_confidence: 验证置信度

3. 创建测试脚本验证功能

## 验收标准

- ✅ 能成功加载 YOLO 模型
- ✅ 能对单张图片进行推理
- ✅ 能对批量图片进行推理
- ✅ 输出格式符合规范
- ✅ 保留原始置信度
